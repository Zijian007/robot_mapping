# 栅格与点云清理

算法细节及适用边界；日常启动见 [GDK 使用说明](../../robot_mapping_gdk/README.md)。

## 2D 射线清空

会话默认启用 `grid.ray_clearing`。每次有效栅格观测保存真实激光起点和回波终点，
前后雷达分别使用自己的起点，两者一起转换到帧末 IMU 坐标并去畸变。
栅格按 `height_resolution: 0.2` m 分层积累证据，再导出 2D 占用状态。
不同高度层的射线不能互相清除障碍；同帧命中优先于空闲证据，重复点只计一次。

每层分值按下表规则更新（默认值）：分值范围 `[-4,8]`，命中加 2、穿过减 1，达到 3 才确认占用。
因此从零分值开始，至少两次观测命中才确认障碍；单次命中的格子保持未知。

| 参数 | 默认 | 含义 |
|---|---|---|
| `grid.score_hit` | 2 | 一次观测中该层被命中时加的分，整数 1～127 |
| `grid.score_miss` | 1 | 一次观测中射线穿过该层时减的分，整数 1～127 |
| `grid.score_max` | 8 | 分值上限，整数，不小于 `score_occupied`，不超过 127 |
| `grid.score_min` | -4 | 分值下限，整数 -128～-1；负分值才算该层空闲证据 |
| `grid.score_occupied` | 3 | 任一层达到该值即输出占用，整数 1～`score_max` |

这些规则同时作用于 Python 参考实现和 C++ 扩展，回环重建使用同一规则。
在通用默认 `grid.free_space_mode: "height_complete"` 下，配置高度范围内
**每一层都有负分值**时才输出空闲；任意一层未观测或分值为零，整列保持未知。
旧障碍被清除后也可能变成未知，不自动成为可通行区域。没有回波不产生空闲证据，
也不会清除回波终点后方。当前机器人脚下仍保留半径 `free_radius_m` 的临时空闲先验，
但任何正分值（包括单次命中）优先于该先验；离开后恢复证据决定的状态。
这是离散高度层覆盖检查，不代表连续空间、配置高度范围外或机器人整个体积已被验证为空。
严格覆盖会增加未知区域，导航端不能把未知直接当作可通行；不要为增加白色区域而缩窄高度范围。

### 二维可见性投影

`grid.free_space_mode: "projected"` 将二维自由证据与高度层障碍证据分开保存：

- 仅用起点和回波高度均在配置范围内的真实射线，按原预算/分组选取；仍受最大射程限制，终点不计为空闲。
- 二维射线途经的格子需达到 `grid.projected_min_observations` 次有效观测才判空（默认 2）；同次观测重复射线只计一次。
- 当前任何高度的命中，以及历史任意高度的正障碍分值，均阻断二维清空射线。
  新命中立即重置该列的二维自由次数，即使之前的负分值还未被抵消，也不继续把它画白。
- 障碍用真实三维射线、分层分值和同帧命中优先规则清除。
  高处穿透不会清除低处障碍；二维自由证据不修改高度层分值或三维点云。
- 当前脚下的临时先验保留，但不能覆盖当前命中。回环按时间顺序重放二维证据，重置时一并清空。

这是平面导航地图的可见性推断，不要求所有高度都已被测量；它依赖场景观测，不能验证尚未见到的
悬空障碍或地面支撑。`grid.free_space_mode` 默认 `height_complete`。

可在 GDK 的 `g2_mapping.yaml` 中调节以下参数，本机当前使用较保守的 4 次 / 5 m：

```yaml
grid:
  free_space_mode: projected
  projected_min_observations: 4
  projected_max_range: 5.0
```

| 参数 | 含义 | 调整方向 |
|---|---|---|
| `projected_min_observations` | 同一格判空需要的有效观测次数，整数 1～127 | 越大越慢变白；可先在 3～6 间试验 |
| `projected_max_range` | 从真实传感器起点沿三维射线计的二维判空距离上限，单位 m，必须为有限正数 | 越小越限制远处扩展；可先在 3～8 m 间试验 |

默认 2 次、30 m，两者都必须是具体数值，不接受 `null`。
判空距离还受 `grid.max_ray_range` 上限限制。它只限制二维自由次数的新增，不影响远处障碍命中、
高度层清除证据或三维体素清理。累计次数不是连续帧数或固定秒数，观测不必来自不同位置。
地图会保留过去已观测的自由格；移动后地图仍可超出当前传感器周围 5 m。
这两个参数仅在 `projected` 模式生效，脚下临时先验仍由 `online.free_radius_m` 控制。
修改配置后需重新启动建图；不会实时重算正在运行的会话或改写已保存地图。

`max_ray_range: 30.0` m 限制 2D 更新范围；`grid.max_rays`（通用默认 2048）限制每个关键帧的
清空射线数（定时观测使用同一限额），按角度、高度和起点分组选取近处回波，再均匀限额；范围内所有真实回波
仍提供命中证据。回环按修正后的位姿重放保存的射线，重建同样的分值。

除几何关键帧外，`grid.update_interval_s: 1.0` 允许每隔至少 1 秒传感器时间补充
一次有效观测，因此静止时也能更新。设置为 0 恢复只按关键帧更新。重复时间戳、
无效匹配不计数；传感器停止后不会按墙钟自行“清空”地图。1 秒是观测间隔，
不是清除期限：达到分值上限 8 的高度层至少需要 9 次同层穿透观测才能变成负分值，
整列还需满足其他高度层的空闲证据条件。

### 动态目标拖影

人或车辆停留过的高度层会累积到分值上限；离开后要有足够多的同层穿透观测才能清掉。
默认规则下，饱和的层需要 6 次穿过才不再输出占用，`projected` 模式下还要降到 0 以下
（8 次）并重新累计二维空闲次数才会变白。射线穿过后须在 `max_ray_range` 内有回波，
后方空旷、玻璃或超出射程的位置不会得到清除证据。

加快清除的方向及代价：

- 降低 `score_max`（如 4）：已饱和的拖影 2 次穿过即不再占用；长期障碍偶尔被误穿透时也更容易被清掉。
- 提高 `score_miss`（如 2～3）：所有障碍的清除都更快，对配准误差和细小结构更敏感。
- 降低 `grid.update_interval_s`：静止时观测更频繁，按时间计的清除更快；存档内存和回环重建时间增加。
- 保持 `score_occupied` 大于 `score_hit`：否则单次命中即确认，传感器噪声会直接成为障碍。

调参前后可用 GDK `tools/evaluation/` 中的工具在同一录包上离线对比。

定时观测绑定到最近的几何关键帧，并保存相对位姿；不增加回环节点、不向 3D
体素图添加点。回环按时间顺序重投影全部观测，并补齐重建期间到达的新观测，
避免静止时的清理结果丢失。更多观测会增加存档内存和回环重建时间，长会话可调大间隔。
人在离开后原位置没有再次被有效射线覆盖，仍可能留痕。仅调用 `OnlineMap()` 的底层用户默认仍使用旧投影；开启
`ray_clearing=True` 后必须提供同帧 `scan_body_rays`，不以猜测的起点代替缺失数据。
底层定时更新还需设置 `grid_update_interval_s` 并提供 `stamp`；`ingest_odom` 自动
使用 LIO 的源时间。摄入函数返回值仍表示是否添加几何关键帧，定时更新会返回 False；
`stats().grid_observations` 单独统计栅格观测数量。

## 3D 点云残影清理

会话默认启用 `online.voxel_clearing: true`，作用于持久化体素图和保存的 `map.pcd`。
使用同一批有效关键帧和定时观测的真实去畸变射线，独立判断三维体素，**不根据 2D 空闲格删除整列点**，
也不受 2D 高度裁剪范围限制。FAST-LIO 内部匹配地图及原始关键帧点云继续保留。

- 射线以半个体素边长为步长采样，只有穿过体素内部中央 60% 区域的样本才提供清除证据；擦边不计。
- 在回波前两个体素边长处停止清除，范围受 `grid.max_ray_range` 限制；不延伸到回波后方。
- 所有当前回波保护所在体素及其 26 邻域，即使该射线没有进入清除采样子集。新命中会重置该体素的累计清除次数。
- `online.voxel_clear_observations: 3` 表示至少三次有效观测提供穿透证据才删除；重复射线每次观测只计一次，未观测不会按时间自动删除。
- 每次最多用 `online.voxel_max_rays` 条清除射线，按起点、方位角和俯仰角分组选近处回波；漏采样只会让清理更慢。
  默认 2048，与二维 `grid.max_rays` 分别设置；可将二维预算设为 8192 而三维保持 2048，增加二维覆盖而不提高三维清理预算。

定时观测可以删除旧体素，但不添加新几何点或回环节点；新增点仍来自几何关键帧。
回环按时间顺序重放“关键帧插入 → 观测清理”，并补齐重建期间的新观测，防止旧残影复活或后出现的物体被早期射线删除。
状态中的 `removed_voxels` 是当前位姿重建下的累计删除事件数，不是人体点数；同一体素重新出现后可以再次删除。

设置 `online.voxel_clearing: false` 可关闭 3D 清理；若同时关闭 `grid.ray_clearing`，两项都必须设为 false。
直接使用底层 `OnlineMap` 时需显式设置 `ray_clearing=True, voxel_clearing=True`；静止清理还需正的
`grid_update_interval_s` 和传感器时间戳。这是几何证据过滤，未再次观测的残影仍会保留；细小结构、位姿误差和体素量化仍可能导致误删。
