# 栅格与点云清理

算法细节及适用边界；日常启动见 [GDK 使用说明](../../robot_mapping_gdk/README.md)。

## 2D 射线清空

会话默认启用 `grid.ray_clearing`。每次有效栅格观测保存真实激光起点和回波终点，
前后雷达分别使用自己的起点，两者一起转换到帧末 IMU 坐标并去畸变。
栅格按 `height_resolution: 0.2` m 分层积累证据，再导出 2D 占用状态。
不同高度层的射线不能互相清除障碍；同帧命中优先于空闲证据，重复点只计一次。

每层分值范围 `[-4,8]`，命中加 2、穿过减 1，达到 3 才确认占用。
因此至少两次观测命中才确认障碍；单次命中的格子保持未知。射线只有在配置高度范围内
**每一层都有负分值**时才输出空闲；任意一层未观测或分值为零，整列保持未知。
旧障碍被清除后也可能变成未知，不自动成为可通行区域。没有回波不产生空闲证据，
也不会清除回波终点后方。当前机器人脚下仍保留半径 `free_radius_m` 的临时空闲先验，
但任何正分值（包括单次命中）优先于该先验；离开后恢复证据决定的状态。
这是离散高度层覆盖检查，不代表连续空间、配置高度范围外或机器人整个体积已被验证为空。
严格覆盖会增加未知区域，导航端不能把未知直接当作可通行；不要为增加白色区域而缩窄高度范围。

`max_ray_range: 30.0` m 限制 2D 更新范围；`max_rays: 2048` 限制每个关键帧的
清空射线数（定时观测使用同一限额），按角度、高度和起点分组选取近处回波，再均匀限额；范围内所有真实回波
仍提供命中证据。回环按修正后的位姿重放保存的射线，重建同样的分值。

除几何关键帧外，`grid.update_interval_s: 1.0` 允许每隔至少 1 秒传感器时间补充
一次有效观测，因此静止时也能更新。设置为 0 恢复只按关键帧更新。重复时间戳、
无效匹配不计数；传感器停止后不会按墙钟自行“清空”地图。1 秒是观测间隔，
不是清除期限：达到分值上限 8 的高度层至少需要 9 次同层穿透观测才能变成负分值，
整列还需满足其他高度层的空闲证据条件。

定时观测绑定到最近的几何关键帧，并保存相对位姿；不增加回环节点、不向 3D
体素图添加点。回环按时间顺序重投影全部观测，并补齐重建期间到达的新观测，
避免静止时的清理结果丢失。更多观测会增加存档内存和回环重建时间，长会话可调大间隔。
人在离开后原位置没有再次被有效射线覆盖，仍可能留痕。仅调用 `OnlineMap()` 的底层用户默认仍使用旧投影；开启
`ray_clearing=True` 后必须提供同帧 `scan_body_rays`，不以猜测的起点代替缺失数据。
底层定时更新还需设置 `grid_update_interval_s` 并提供 `stamp`；`ingest_odom` 自动
使用 LIO 的源时间。摄入函数返回值仍表示是否添加几何关键帧，定时更新会返回 False；
`stats().grid_observations` 单独统计栅格观测数量。

## 3D 点云残影清理

会话默认启用 `online.voxel_clearing: true`，作用于持久化体素图和保存的 `map.pcd`。
使用同一批有效关键帧和定时观测的真实去畸变射线，独立判断三维体素，**不根据 2D 空闲格删除整列点**，
也不受 2D 高度裁剪范围限制。FAST-LIO 内部匹配地图及原始关键帧点云继续保留。

- 射线以半个体素边长为步长采样，只有穿过体素内部中央 60% 区域的样本才提供清除证据；擦边不计。
- 在回波前两个体素边长处停止清除，范围受 `grid.max_ray_range` 限制；不延伸到回波后方。
- 所有当前回波保护所在体素及其 26 邻域，即使该射线没有进入清除采样子集。新命中会重置该体素的累计清除次数。
- `online.voxel_clear_observations: 3` 表示至少三次有效观测提供穿透证据才删除；重复射线每次观测只计一次，未观测不会按时间自动删除。
- 每次最多用 `grid.max_rays` 条清除射线，按起点、方位角和俯仰角分组选近处回波；漏采样只会让清理更慢。

定时观测可以删除旧体素，但不添加新几何点或回环节点；新增点仍来自几何关键帧。
回环按时间顺序重放“关键帧插入 → 观测清理”，并补齐重建期间的新观测，防止旧残影复活或后出现的物体被早期射线删除。
状态中的 `removed_voxels` 是当前位姿重建下的累计删除事件数，不是人体点数；同一体素重新出现后可以再次删除。

设置 `online.voxel_clearing: false` 可关闭 3D 清理；若同时关闭 `grid.ray_clearing`，两项都必须设为 false。
直接使用底层 `OnlineMap` 时需显式设置 `ray_clearing=True, voxel_clearing=True`；静止清理还需正的
`grid_update_interval_s` 和传感器时间戳。这是几何证据过滤，未再次观测的残影仍会保留；细小结构、位姿误差和体素量化仍可能导致误删。
